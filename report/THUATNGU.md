# Thuật ngữ dùng thống nhất

Cả nhóm dùng **một** cách gọi cho mỗi khái niệm. Bổ sung dòng mới khi gặp thuật ngữ chưa có; cần đổi thì báo cả nhóm.

| Khái niệm | Dùng trong báo cáo | Không dùng lẫn với |
|---|---|---|
| Accelerator | bộ tăng tốc | accelerator / bộ gia tốc (chỉ viết tiếng Anh trong ngoặc ở lần đầu) |
| Host | máy chủ (host) ở lần đầu, sau đó "host" | PC / máy tính (chỉ dùng khi nói về phần cứng PC) |
| Pipeline | pipeline (giữ nguyên) hoặc "đường ống" ở lần đầu | luồng xử lý |
| Layer | lớp (layer) khi nói về mạng; "layer" khi nói về lệnh CONFIG/RUN | tầng |
| Feature map | bản đồ đặc trưng (feature map) | |
| Beat | nhịp (nhịp tim) | beat |
| Bit-exact | khớp từng bit (bit-exact) | giống hệt |
| Golden | mô hình/vector chuẩn (golden) | |
| Lượng tử hoá | lượng tử hoá int8 | quantization (chỉ trong ngoặc) |
| Mảng PE | mảng PE (PE array), mảng systolic | lưới PE |
| Tile | ô (tile) tính toán | mảnh |
| Bank | bank (giữ nguyên) | bộ đệm |
| Ping-pong | bộ đệm ping-pong | |
| Se, +P | độ nhạy (Se), độ chính xác dương (+P) | recall/precision (chỉ nêu khi so sánh với công trình khác) |
| DS1, DS2 | tập DS1 (huấn luyện), tập DS2 (kiểm tra liên bệnh nhân) | train/test set |
| Tên lệnh UART | giữ nguyên chữ in hoa, đặt trong `\texttt{}`: `WRITE_X`, `CONFIG`, `RUN` | |
| Tên module RTL / file | `\texttt{layer\_cmd\_controller}` | |
| Đơn vị | số và đơn vị cách nhau một khoảng trắng nhỏ: `50\,MHz`, `41{,}17\,ms` hoặc `41.17\,ms` (chọn một kiểu cho cả báo cáo) | |

**Dấu thập phân:** chọn *một* kiểu cho cả báo cáo (chấm `0.603` hoặc phẩy `0{,}603`) và ghi vào đây: **[chưa chốt]**.
